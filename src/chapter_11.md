在这一章中，我们会看到一个例子。它是一个看起来自然而且“无计算”的问题，尽管如此，它却是不可计算的：求解丢番图方程。作为一个推论，我们会看到20世纪数学界最令人震惊的结果之一——哥德尔不完备定理，它表示存在一些数学（事实上是数论）断言**本质上无法证明**。我们将从结果开始讲，之后再讲证明。

## 希尔伯特计划和哥德尔不完备性定理

```admonish quote
“这些……消失的增量是什么呢？它们既不是有限量，也不是无限小的量，更不是虚无。难道我们不能称它们为‘消逝量的幽灵’吗？”

————乔治·贝克莱（George Berkeley），1734
```
18世纪和19世纪是一个数学上大发现的年代，但同时也是一个出现数学危机的年代。牛顿和莱布尼茨在17世纪末发现的微积分引领了一个解决问题的黄金时代。很多长期未解决的问题屈服于新发现的工具，而数学家们在做令人实在印象深刻的计算方面做的甚至更好。然而，这些计算背后的严格基础还有很多不足之处。数学家们漫不经心地操纵无穷小量和级数，虽然大部分时候他们可以得到正确的答案，仍然存在一些怪异的例子（例如尝试计算无穷级数$1-1+1-1+1+\ldots$），根据计算方法的不同，似乎会给出不同的答案。这导致对这门学科的基础的不安感越来越大，而最终被柯西（Cauchy），魏尔斯特拉斯（Weierstrass）和黎曼（Riemann）解决。他们给了分析学一个更加坚实的基础，由此产生了至今仍然令学习高等微积分课程的学生苦苦应对的$\epsilon-\delta$语言。

在20世纪初，人们试图以更高的严谨性，将这一努力推广到数学的各个领域，希望证明所有正确的命题都可以被由一些公理出发，用推理的逻辑规则生成。这种努力被称作**希尔伯特计划**，由著名的数学家大卫·希尔伯特命名。

可惜，事实是我们看到的结果给这个计划造成了毁灭性的打击。正如哥德尔在1931年证明的那样：

```admonish quote title=""
{{thmc}}{thm:godethminformal}[哥德尔不完备性定理：非正式模式] 

对于任何一个可靠的且能表达足够丰富数学命题的证明系统 $V$，都存在一个数学断言，它是**真**的，但在 $V$ 中是**不可证明的**。
```

### 定义“证明系统”{#sec11.1}

在证明[#定理11.1](t11.1)之前，我们需要定义什么是“证明系统”，甚至形式化的定义“数学断言”的概念。在几何于其他一些数学领域，证明系统经常被定义为从一些基础的假设或者**公理**开始，然后通过使用**推理规则**导出更多的命题，例如著名的[肯定前件](https://en.wikipedia.org/wiki/Modus_ponens)，但是我们需要用什么公理？什么规则？我们将使用一个极为广泛的证明系统概念，甚至不局限于具有公理和推理规则形式的系统。

**数学断言**：在最高一层，一个数学断言只是一段文字，我们可以把它当成一个**字符串** $x \in \{0, 1\}^*$。数学断言包括一些断言，其正确性不依赖于任何经验试试，而只表示抽象概念的性质。
例如，下面是一个数学断言：^[这是一个**错的**断言]
> 数字 $2$,$696$,$635$,$869$,$504$,$783$,$333$,$238$,$805$,$675$,$613$, $588$,$278$,$597$,$832$,$162$,$617$,$892$,$474$,$670$,$798$,$113$都是质数。

数学断言不一定要含有数字。他们可以断言其他任何数学对象的性质，包括几何，字符串，函数，图，甚至**程序**。
因此，数学断言的另一个性质如下，

```python
def f(n):
    if n==1: return 1
    return f(3*n+1) if n % 2 else f(n//2)
```
**证明系统**：对一个定理$x \in \{0, 1\}^*$的**证明**也是一个字符串$w \in \{0, 1\}^*$

1. 有效性 给定一个断言$x$和一个证明$w$，存在一个算法来验证$w$是否是$x$的证明（比如一行一行的确认每一行都是由合法的推理规则从前一行推导出来的。

2. 可靠性 若对于$x$，存在一个合法的证明$w$，则$x$为真。

这些是对于一个证明系统的很少的要求。第二个要求（可靠性）正是形式系统的定义：你不应该能证明一个假的命题。第一个要求也是必要的。如果没有一组推理规则（换句话说，一个算法）来检查一个证明是否合法，那么它怎么能称之为证明系统呢？我们倒不如直接把它替换为这样一个系统：对于任何断言，证明都是“相信我，这是真的”。

形式化的，我们定义证明系统为这样一个算法$V$：$V(x, w) = 1$当且仅当$w$是$x$的一个合法证明。即使$x$为真，$w$也不一定合法（对于一个正确的断言如$2+2=4$，有很多中错误的证明方法），但是如果$w$合法，那么$x$一定为真。

```admonish quote title=""
{{defc}}{def:proofsystemsdef}[证明系统]

令$\mathcal{T}\subseteq\{0, 1\}^*$是所有正确断言的集合。
$\mathcal{T}$的一个**证明系统**是满足下列两个条件的算法$V$：
1. 有效性 对任意$x, w \in \{0, 1\}^*$，$V(x,w) = 0$。
2. 可靠性 对任意$x \notin \mathcal{T}$和$w \in \{0, 1\}^*$，$V(x,w) = 0$。

一个正确断言$x \in \mathcal{T}$是（在$V$中）**不可证明**的，如果$\forall w \in \{0, 1\}^*$，$V(x, w) = 0$。而如果在$V$中任意命题都可证明，那么我们称$V$为**完备的**。
```

```admonish bigidea
{{idec}}{ide:proofsystems}
一个**证明**就是一个字符串，它的意义是由**证明算法**赋予的。
```
